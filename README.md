# Sukebei Nyaa 浏览增强

用于 `sukebei.nyaa.si` 的油猴脚本：**列表详情在新标签页打开，详情页的图片链接自动显示为图片**。

脚本文件：[nyaa-description-images.user.js](nyaa-description-images.user.js)

## 功能介绍

### 1. 列表详情在新标签页打开

在首页、搜索结果等种子列表中，左键点击条目标题，会在新标签页打开详情，原列表页保留，方便继续浏览。

- 列表中的评论链接也在新标签页打开，并保留评论定位。
- 分类、排序、分页、种子下载和磁力链接维持原有行为。
- 动态追加的列表条目也会自动处理。

### 2. 详情页自动显示图片

种子描述中原本只有网址的图片链接，会自动转换成图片，并按内容区宽度等比例缩放。

| 状态 | 页面表现 |
| --- | --- |
| 解析或加载中 | 原链接前显示转圈图标，链接仍可点击 |
| 加载成功 | 显示图片，移除转圈图标 |
| 加载失败或超时 | 显示感叹号和原链接，悬停感叹号可查看失败原因 |

成功显示后，**左键点击图片及外层链接的空白区域均不会跳转**，避免误触。失败时，原链接仍可正常打开。

脚本也会处理描述区后续动态追加的图片链接。

### 3. 自动解析 ImageTwist 展示页

有些 ImageTwist 地址虽然以 `.jpg` 结尾，实际打开的是展示网页，不能直接当作图片使用。脚本会先读取展示页，提取真实原图地址，再加载图片。

- 支持 `imagetwist.com` 及其所有子域名的 HTTPS 原图地址，原图路径须以 `/i/` 开头。
- 只解析展示页内容，不执行图床页面里的脚本。
- 解析失败、图片失效或请求超时时，显示感叹号并保留原链接。

## 安装与更新

1. 在浏览器中安装并启用 Tampermonkey（油猴）。
2. 在油猴中选择“添加新脚本”；更新时打开已有的本脚本。
3. 将 [nyaa-description-images.user.js](nyaa-description-images.user.js) 的**全部内容**复制到编辑器中，替换原有内容并保存。
4. 如果油猴提示允许连接 `imagetwist.com`，选择允许，以便解析图床展示页。
5. 刷新 Sukebei Nyaa 页面。

更新时请保留完整的脚本头部，包括 `@match`、`@grant` 和 `@connect` 声明，否则可能无法匹配页面或解析 ImageTwist。

## 支持范围

| 项目 | 范围 |
| --- | --- |
| 网站 | `https://sukebei.nyaa.si/*`，包括首页、带搜索参数的页面和详情页 |
| 列表链接 | `table.torrent-list` 表格内、指向本站 `/view/数字` 的详情链接 |
| 图片转换区域 | 详情页的种子描述区 `#torrent-description` |
| 图片格式 | JPG、JPEG、PNG、GIF、WebP、AVIF、BMP、SVG，支持带查询参数的地址 |
| 图床展示页解析 | ImageTwist；其他图床目前仅尝试直接加载图片链接 |
| 超时时间 | ImageTwist 展示页请求最多 15 秒；解析和图片加载总计最多 45 秒 |

链接需要在 URL 路径末尾带有上述图片扩展名，才会进入图片转换流程。无扩展名的图片接口地址暂不自动识别。

## 故障排查

### 查看日志

按 **F12 → Console（控制台）**，启用 Info、Warning、Error 日志级别，筛选 `[NyaaImages]`，然后刷新页面。

| 日志或现象 | 含义与检查方向 |
| --- | --- |
| 没有“启动”日志 | 清除控制台筛选，检查油猴和脚本是否启用、脚本是否保存、当前域名是否匹配 |
| “当前为列表页，无需转换描述图片” | 正常提示；列表页只处理详情链接 |
| “列表详情链接已设为新标签页打开” | 对应条目已处理，新标签页功能已生效 |
| “未找到描述区，等待 DOM 更新” | 暂未找到描述区；内容出现后会自动扫描 |
| “跳过链接” | 链接不满足转换条件，具体原因见日志 |
| “ImageTwist 展示页响应” | 可查看展示页请求的 HTTP 状态码和 Content-Type |
| “解析到真实图片地址” | 展示页解析成功，接下来加载原图 |
| “跳过原图候选地址” | 候选地址未通过协议、域名或原图路径检查 |
| “图片已显示” | 转换成功，日志包含图片尺寸和加载耗时 |
| “图片失败，保留原链接” | 查看失败原因；需要进一步排查时，到 Network 面板检查实际请求 |
| “页面 CSP 图片策略事件” | 页面报告了图片加载策略限制，也可能来自页面上的其他图片 |

图片的 `error` 事件不提供 HTTP 状态码或响应正文。排查原图加载失败时，请在 **Network（网络）** 面板按图片地址查找请求，检查状态码、Content-Type、重定向和响应内容。

### 导出诊断信息

在控制台执行：

```js
NyaaImagesDebug.snapshot()
```

返回 JSON 格式的诊断信息，包含运行版本、当前页面、处理统计和最近最多 2000 条日志。分享前可检查其中的页面及图片 URL。

也可以手动扫描新链接：

```js
NyaaImagesDebug.scan()
```

手动扫描不会重新请求已经处理过的图片链接；如果需要重试加载失败的图片，请刷新页面。
